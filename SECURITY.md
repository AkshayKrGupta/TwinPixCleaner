# Security Policy

## Supported Versions

The following versions of TwinPixCleaner are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

The security of TwinPixCleaner and its users is taken seriously.

If you discover a security vulnerability, please report it responsibly using **GitHub Private Vulnerability Reporting**.

Please avoid publicly disclosing security vulnerabilities until they have been reviewed and addressed.

### What to include in your report

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact if exploited.
- Any suggested fixes or mitigations.

We will acknowledge and investigate all legitimate reports as soon as possible.

Thank you for helping improve the security and reliability of TwinPixCleaner.
